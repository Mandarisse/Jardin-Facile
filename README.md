# 🌱 Jardin Facile

Site web de services professionnels d'entretien de jardins et d'aménagement paysager.

## 🛠️ Technologies

- React 18
- Vite
- React Router DOM

## 📦 Installation
```bash
npm install
npm run dev
```

## 🔄 Workflow Git

Ce projet utilise Git Flow avec :
- `main` : version de production
- `develop` : branche de développement active
- `feature/*` : branches de fonctionnalités

### Note sur l'historique Git

> **Note :** Le setup initial (Vite + React) est présent à la fois dans `main` et `develop`. 
> À partir de ce point, tout le développement se fait via des branches `feature/*` 
> fusionnées dans `develop` via Pull Requests. La branche `main` ne sera mise à jour 
> qu'à la release finale.
